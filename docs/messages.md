# 消息类型处理

微信 Hook 把每条消息推成 `{type, content}` 两个字段，`content` 可能是纯文本，也可能是一段 XML。
`MediaMessageParser` 负责把非文本消息翻译成「可读文本 + 元数据」，这段文本会：

1. 存进 `message_log.content`（管理端会话记录直接展示）；
2. 原样进入模型上下文（历史消息也只回放这段文本）；
3. 作为引用消息的「被引用原文」再被引用一次。

设计原则：**解析不出来也要留得下消息**。任何陌生格式都退化成占位文本，绝不因为格式没见过而丢消息。

| --- | --- | --- | --- |

| 缺失 / 其它 | — | 看内容特征 | 有 `<filename>` / `<fileext>` / `totallen>0` → `FILE`；有 `<url>` → `LINK`；否则 `OTHER`（`[卡片] 标题`） |

### 两个踩过的坑

- **链接卡片也带 `<appattach>` 空壳**（`totallen=0`、`fileext` 为空）。早先「有 appattach 就算文件」，
  小红书这类分享链接会被渲染成 `[文件] …`，整段分享文案塞进文件名。现在只认真正的文件字段。
- **`<type>` 的位置不固定**：引用消息里它可能排在 `<content>` 之后。取类型时要先把 `<content>` 段摘掉，
  再在整个 `<refermsg>` 里找，否则被引用的图片会被当成文字，抽出 `eyJwaGFzaCI6…` 这种 base64 垃圾串。

## 三、引用回复（appmsg 子类型 57）

`parseQuote` 把消息拆成两部分：

- `text`：用户这次说的话（外层 `<title>`）；
- `quoteAuthor` / `quoteText`：被引用那条消息的发送者与内容，**按它自己的类型重新渲染**，
  所以被引用的可以是图片（`[图片]`）、语音（`[语音 4″]`）、文件（`[文件] 报价单.pdf`）、链接等；
- `media`：被引用的是图片时带上 md5 / 缩略图 md5，用于把那张图也发给模型看；
- `quoteEpochSeconds`：被引用消息的发送时间，按它（而不是回复时间）去找本地月份目录。

进模型前会被排成两段（`ChatOrchestrator.quoteBlock`）：

```
【引用的消息｜来自 无关人物】
6
【我这次说的话】
@小助手 我引用了什么消息
```

单行 `[引用 张三：6]` 的写法模型会当成读不懂的标记，从而回答「我看不到具体内容」——这是之前的线上问题，
改成两段并配一条系统说明后，模型会照实复述被引用的原文。引用里再套引用会再拆一层。

## 四、进模型前的额外说明

| 场景 | 注入的系统提示 |
| --- | --- |
| 本条带引用 | `QUOTE_HINT`：被引用那段就是真实原文，不要回答「看不到」 |
| 本条是语音 | `VOICE_HINT`：只能看到时长，听不到内容，不许编 |
| 本条是图片但本地取不到文件 | `IMAGE_MISSING_HINT`：看不到画面，不许编 |
| 图片只有缩略图 | 内容末尾追加「分辨率有限，细节可能看不清」 |

## 五、回复策略

- 媒体消息受「媒体策略」控制（`media.enabled` / `media.replyMode`：`ignore` 只记录、`ack` 固定话术、`llm` 交给模型）。
- 群聊里媒体消息没有文字，通常不含唤醒词，因此**只记录不回复**；引用回复带文字，会正常命中唤醒词。
- 私聊按 `replyPrivate` 决定是否回复。

## 六、已知限制

| 类型 | 限制 | 现在怎么处理 |
| --- | --- | --- |
| 语音 | Hook 不提供转写能力 | 只报时长，并明确告诉模型「听不到」 |
| 表情 | 表情包是加密 `.dat`，没有可读文字 | 只报 `[表情]` |
| 图片 | 依赖本机 `xwechat_files` 里的 `.dat`；高清副本可能是 HEVC，解不了就用缩略图 | 取不到就退回 `[图片]` + 说明 |
| 位置 / 名片 | 只有 XML 里的名称与地址 | 原样带出，不做地理编码 |
| 合并转发 | 只给标题与摘要，不含内层逐条内容 | 需要细节时请对方直接转发 |

## 七、怎么自查

- **看原始报文**：管理端「诊断」页的最近回调，或 `GET /api/admin/diagnostics`。
- **复现引用**：`POST /api/admin/debug/chat`，带 `quoteAuthor` / `quoteText`。
- **复现媒体**：同一个接口带 `mediaKind`（如 `VOICE` + 内容 `[语音 5″]`）。
- **单测**：`MediaMessageParserTypesTest` 覆盖上面每一行渲染规则，`MediaMessageParserTest` 覆盖引用拆解。
